**Auto** at the top of the **Servers** tab hands the choice to Xray's balancer. Every server is
loaded into the core at once, so switching between them needs no reconnect and never drops the
tunnel.

## Two modes

| Mode | How it picks | Good for |
| --- | --- | --- |
| **Lowest delay** | all connections use the server with the lowest delay; if it stops answering, the next one takes over | everyday use, games, calls |
| **Round robin** | each new connection goes to the next live server | spreading load so no single server hits its limit |

The mode is switched under **Auto**. With the VPN on, the app reconnects in the new mode.

## How delay is measured

While the VPN is on, the core tests every server every 30 seconds with a request to
`https://www.gstatic.com/generate_204`. The server list shows the same numbers, and in
lowest-delay mode Home shows the server in use ("Now: …").

A server that does not answer is marked "timeout" and skipped in both modes until it answers
again. Before the first measurement, the last chosen server, or the fastest from the last test,
is used.

## Picking by hand

Tapping a server pins it and the balancer stops switching. Tap **Auto** to hand the choice back.
