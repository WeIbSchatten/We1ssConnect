We1ssConnect adds a tile to Android's quick settings to turn the VPN on and off without
opening the app.

## Adding it

1. Pull the notification shade all the way down with two swipes.
2. Tap the pencil (**Edit**).
3. Find the **We1ssConnect** tile and drag it to the top part.

## How it works

- **Tap** connects with the last server and settings, or disconnects.
- **Long press** opens the app.
- While connected the tile is lit and shows the server under its name.

If the VPN was never started from the app, or its permission was taken away, the tile opens the
app so you can connect and grant it.

## Notification

While the VPN runs, a notification shows the server and a **Disconnect** button. Android
requires it for every VPN, so it cannot be hidden.
