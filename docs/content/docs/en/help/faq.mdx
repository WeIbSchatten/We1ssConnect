## A Reality server does not connect

Make sure **Settings → Chrome fingerprint for Reality** is on. Servers on Xray 26.9.8 and newer
drop clients without X25519MLKEM768, and some links fail without this setting.

## Every server says "timeout"

- Test the delay with the VPN off: **Test delay** on the **Servers** tab.
- Update the subscription: the keys or addresses may have changed.
- If your provider interferes with TLS, turn on **TLS fragmentation**.
- An expired subscription shows on the traffic card on Home.

## Connected, but sites do not open

- Turn **IPv6** off if you turned it on: many servers do not support it.
- Change the DNS resolver or turn on **DNS over HTTPS**.
- In **Only selected apps** mode only ticked apps use the VPN; check that the browser is ticked.

## Russian sites are slow or do not open

Turn on **Russian sites directly**. Many Russian services refuse foreign IP addresses.

## An app is missing from the per-app list

Turn on **Show system apps**: Android counts some apps as system ones.

## The tile opens the app instead of connecting

That happens until the VPN has been started from the app once, or after another VPN took the
permission. Connect once from the app and the tile works.

## An update does not install

- Allow We1ssConnect to install apps when Android asks.
- If you installed a test build signed with another key, remove it and install the release.
- If the download breaks off, get the APK from the
  [release page](https://github.com/WeIbSchatten/We1ssConnect/releases/latest) by hand.

## Can other apps tell I use a VPN?

The core runs inside the app and opens no local ports, so other apps cannot find it by scanning
ports on the phone. Android itself tells apps that a VPN is on (the key icon); no client can hide
that.

## Reporting a bug

Open a [GitHub issue](https://github.com/WeIbSchatten/We1ssConnect/issues) with the phone model,
Android version, app version (Settings → About), the server's protocol and what goes wrong.
