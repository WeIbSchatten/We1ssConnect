## 1.9.1

- Router: We1ssConnect installs next to podkop, Passwall, OpenClash and other clients. On install and on Connect, the ones running or enabled at boot are stopped and lose their autostart, nothing removed; the overview shows what was stopped ([details](../openwrt/troubleshooting.mdx#other-clients-podkop-passwall-openclash)).
- Diagnostics flags another client only while it runs.

## 1.9.0

- **We1ssConnect for OpenWrt 24.10 and 25.12 routers** on sing-box from the OpenWrt packages: subscriptions and keys, the lowest-delay Auto with pinning without a restart, routing by service lists, presets, domains, subnets and remote lists, an all-traffic mode, rules for devices and the router's VPN interfaces, LuCI pages in Russian and English, a one-line installer ([details](../openwrt/index.mdx)).
- A new documentation site with search and links to the panel docs.
- Client versions follow the We1ssBoard panel: clients 1.9.x go with panel 1.9.x.

## 1.2.0

- **Subscription screen**: traffic, expiry, the panel's subscription page, copy link, refresh and the server list. It opens from the group header or the home traffic card.
- **Telegram proxies** from the subscription (Web Proxy and MTProto): one tap and Telegram offers to add it.
- Windows: country flags instead of the letters FI, DE; tab labels are no longer cut off.

## 1.1.0

- **We1ssConnect for Windows and Linux.** The same screens as on the phone: servers, subscriptions, auto select, routing, ping. Instead of a VPN it turns on the system proxy, and SOCKS5 `127.0.0.1:10808` is there for programs that ignore it. It updates itself from the app.
- One release carries both the APKs and the desktop builds.

## 1.0.1

- Delay is measured to the server itself by default instead of a full request through it, so the numbers are honest and no longer add hundreds of milliseconds. The old way is still in the settings.
- The delay test works with the VPN on too.
- Dialogs and menus are drawn in the app's own style instead of the system's.
- The design is closer to the We1ssBoard panel: the W mark in the header, bordered cards with a soft shadow, a speed and traffic strip.

## 1.0.0 — first stable release

Everything from the test builds, plus:

- **Automatic choice in two modes**: lowest delay and round robin.
- **Hidden IP**: Home hides the middle of the address; tap to show it in full.
- **Key groups**: each batch of links is saved as a named group; groups and subscriptions have
  an update / remove menu.
- **Russian by default** with an English switch; notifications follow the chosen language.
- **Themes**: system, light, dark and AMOLED, with the We1ssBoard panel colours.
- **In-app updates**: checks GitHub releases, downloads the APK for your CPU and installs it.
- **Tile**: a long press opens the app.
- Documentation in Russian and English.

## 0.0.2 — test build

- New interface with **Home**, **Servers** and **Settings** tabs.
- Its own bridge to the core: live ping, automatic choice, speed and traffic, exit IP and
  country, with no local ports.
- Delay tests before and during the connection.
- Per-app routing.
- "Russian sites directly" and "Block ads" presets.
- DNS choice, DNS over HTTPS, IPv6, TLS fragmentation, mux.
- QR code import, copying a server's link.
- Quick settings tile.
- Subscription auto-update.
- Separate ARM64 and ARMv7 APKs instead of one 227 MB file.

## 0.0.1 — first build

- Connections through Xray-core: VLESS, VMess, Trojan, Shadowsocks, Hysteria2.
- Subscriptions with traffic and expiry, share links, the `we1ssconnect://add` link.
- The Reality fix for Xray 26.9.8+.
- A signed APK and an emulator launch check in CI.

## How the app came about

We1ssConnect started on 20 October 2026 as a client for the We1ssBoard panel: one that reads the
panel's subscriptions, deals with the latest Reality changes and depends on no one else's app.
It is written from scratch on Xray-core and libXray. The first build connected and read
subscriptions. The second brought the new interface, automatic server choice, routing and
anti-blocking tools. Version 1.0.0 put it all together with in-app updates and documentation.
