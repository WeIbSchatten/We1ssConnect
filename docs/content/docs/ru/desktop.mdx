Настольная версия использует те же экраны, что и телефон: серверы, подписки, автовыбор,
маршрутизацию, пинг и обновления. Отличие одно: вместо VPN-туннеля она включает системный прокси.

## Какой файл скачать

| Файл | Для чего |
| --- | --- |
| `we1ssconnect-desktop-<версия>-windows-amd64-setup.exe` | установщик для Windows 10 и 11 (64 бит) |
| `we1ssconnect-desktop-<версия>-linux-amd64` | программа для Linux (64 бит) |

## Windows

1. Запустите установщик. Windows может показать «Компьютер защищён»: нажмите
   **Подробнее → Выполнить в любом случае** (у установщика пока нет платной подписи).
2. Нужен WebView2. В Windows 11 он уже есть, в Windows 10 установщик скачает его сам.
3. Запустите We1ssConnect из меню «Пуск».

## Linux

Нужны GTK 3 и WebKitGTK 4.1. В Ubuntu 22.04+ и Debian 12+:

```bash
sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
chmod +x we1ssconnect-desktop-*-linux-amd64
./we1ssconnect-desktop-*-linux-amd64
```

Системный прокси включается в GNOME (через `gsettings`) и KDE (через `kwriteconfig`).
В других окружениях укажите прокси в программе или браузере вручную.

## Как работает подключение

При подключении Xray слушает два порта только на этом компьютере:

| Прокси | Адрес |
| --- | --- |
| SOCKS5 (TCP и UDP) | `127.0.0.1:10808` |
| HTTP | `127.0.0.1:10809` |

Приложение прописывает их как системный прокси, а при отключении или закрытии окна убирает.
Если приложение закрылось аварийно, прокси уберётся при следующем запуске.

Браузеры и большинство программ используют системный прокси сами. Игры, Telegram и программы,
которые его не видят, можно направить на SOCKS5 `127.0.0.1:10808` в их настройках.

## Чего нет в настольной версии

- Маршрутизации по приложениям: системный прокси не различает программы.
- Сканирования QR-кода: ссылку можно вставить из буфера обмена.
- Плитки в шторке.

## Обновление

Как и на телефоне: карточка «Доступна версия…» на главном экране и в настройках. В Windows
приложение скачает и запустит новый установщик, в Linux заменит свой файл новым и перезапустится.
Настройки хранятся отдельно (`%APPDATA%\We1ssConnect` или `~/.config/We1ssConnect`) и сохраняются.
