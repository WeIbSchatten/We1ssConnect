## По приложениям

**Настройки → Маршрутизация по приложениям** решает, какие приложения идут через VPN.

| Режим | Что происходит |
| --- | --- |
| Все приложения | через VPN идёт всё, кроме самого We1ssConnect |
| Только выбранные | через VPN идут только отмеченные приложения, остальные напрямую |
| Все, кроме выбранных | всё через VPN, а отмеченные приложения напрямую (например, банки и госуслуги) |

В списке есть поиск, иконки и переключатель **Показывать системные**. Изменения применяются
при следующем подключении.

> Сам We1ssConnect всегда идёт мимо туннеля: так соединения ядра с сервером не попадают обратно
> в VPN. Поэтому проверка обновлений и скачивание правил идут напрямую.

## Пресеты

| Пресет | Что делает |
| --- | --- |
| **Локальная сеть напрямую** | роутер, принтеры, телевизоры и другие устройства в домашней сети доступны без VPN |
| **Российские сайты напрямую** | домены `.ru`, `.su`, `.рф`, сайты из списка `category-ru` и российские IP-адреса идут мимо VPN; их адреса узнаются через Яндекс DNS, чтобы попадать на ближайшие серверы |
| **Блокировать рекламу** | рекламные и следящие домены из списка `category-ads-all` не открываются |

Для пресетов нужны два файла правил. Они скачиваются при первом подключении с включённым
пресетом и обновляются раз в неделю:

- `geoip.dat` — IP-адреса по странам ([runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat));
- `geosite.dat` — списки доменов ([v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)).

Обновить их вручную можно кнопкой **Обновить правила маршрутизации**.

## DNS

Запросы DNS от приложений перехватываются и уходят через VPN к выбранному резолверу:

- **Cloudflare** (1.1.1.1), **Google** (8.8.8.8) или **Quad9** (9.9.9.9);
- **DNS через HTTPS** — те же резолверы, но запросы зашифрованы;
- **IPv6** — получать и использовать IPv6-адреса, если они есть у сайта и сервера. По умолчанию
  выключено: многие серверы не поддерживают IPv6, и с ним сайты открываются медленнее.
