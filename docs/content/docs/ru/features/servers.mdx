## Группы

Все серверы разложены по группам:

- **подписка** (значок облака) — список с сервера, который можно обновлять;
- **группа ключей** (значок ключа) — ссылки, добавленные вручную или по QR-коду. Каждое
  добавление создаёт новую группу, так что ключи от разных людей не смешиваются.

Нажмите на заголовок группы (или на карточку трафика на главной), чтобы открыть её экран:

- трафик, остаток до лимита и дата окончания подписки;
- **Открыть страницу подписки**: страница панели в браузере, с трафиком и инструкциями;
- **Скопировать ссылку на подписку**, чтобы добавить её на другом устройстве;
- **Обновить подписку**: скачать список заново (только для подписок);
- **Прокси для Telegram**: если панель выдала вам Web Proxy или MTProto, они здесь. Нажмите на
  прокси, и Telegram предложит его добавить. Значок справа копирует ссылку. Такой прокси работает
  сам по себе, VPN для него включать не нужно;
- список серверов группы;
- **Удалить группу**: удалить подписку или группу ключей вместе с её серверами.

## Действия с сервером

- **Нажатие** выбирает сервер. Если VPN включён, переключение происходит на лету.
- **Долгое нажатие** открывает меню: **Скопировать ссылку** (готовая ссылка `vless://…`, чтобы
  поделиться) и **Удалить**.

## Кнопки над списком

| Кнопка | Что делает |
| --- | --- |
| Проверить задержку | измеряет задержку до всех серверов; работает, когда VPN выключен, а во время подключения задержка обновляется сама |
| ⇅ | сортирует серверы по задержке |
| ⟳ | обновляет все подписки (или потяните список вниз) |
| + | добавляет подписку, ключи или QR-код |

## Обновление подписок

С включённой настройкой **Обновлять подписки при запуске** приложение при открытии
обновляет подписки старше 12 часов. Выбранный сервер сохраняется, если он остался в подписке.

Приложение понимает заголовки подписки:

- `profile-title` — название (текстом или `base64:`);
- `subscription-userinfo` — израсходованный трафик, лимит и срок действия, они показываются на
  главной.

## Поддерживаемые протоколы

VLESS (в том числе Reality, XTLS Vision, XHTTP, WebSocket, gRPC), VMess, Trojan, Shadowsocks и
Hysteria2. Подписка может быть в base64, списком ссылок или JSON-конфигом Xray.
