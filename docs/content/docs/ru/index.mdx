We1ssConnect — клиент для серверов на Xray-core и, в первую очередь, для панели
[We1ssBoard](https://weibschatten.github.io/We1ssBoard/ru/docs). Он подключается по подписке или по
ссылкам, сам выбирает самый быстрый сервер, показывает, через какую страну вы вышли в сеть, и
позволяет решить, какой трафик идёт через VPN.

## Возможности

- **Протоколы**: VLESS (Reality, Vision, XHTTP), VMess, Trojan, Shadowsocks, Hysteria2; на
  роутере ещё TUIC, WireGuard и AnyTLS.
- **Пинг до и во время подключения**: задержка до каждого сервера проверяется ещё до
  подключения и обновляется вживую.
- **Автовыбор**: балансировщик берёт сервер с наименьшей задержкой (на телефоне и компьютере —
  ещё и по кругу) и сам обходит упавший сервер. Выбранный вручную сервер переключается без
  переподключения.
- **Ваш IP и страна**: внешний IP (середина скрыта), флаг, город, провайдер, скорость и трафик.
- **Маршрутизация**: по приложениям на телефоне; по спискам, по устройствам и через
  VPN-интерфейсы на роутере; пресеты «Российские сайты напрямую» и «Блокировать рекламу».
- **Против блокировок**: фрагментация TLS, исправление Reality для Xray 26.9.8+, DNS через
  HTTPS.
- **Подписки**: трафик и срок из панели, автообновление, обновление приложения из него самого.

## С чего начать

1. [Установите приложение](./guide/install.mdx) или [пакет для роутера](./openwrt/install.mdx).
2. [Добавьте серверы](./guide/quickstart.mdx): ссылку на подписку из панели, ссылки на ключи
   или QR-код.
3. Нажмите большую кнопку подключения.

## Требования

| | |
| --- | --- |
| Android | 8.0 или новее, ARM64 или ARMv7 |
| Компьютер | Windows 10/11 или Linux с WebKitGTK 4.1, 64 бит ([подробнее](./desktop.mdx)) |
| Роутер | OpenWrt 24.10 или 25.12, около 25 МБ свободной памяти ([подробнее](./openwrt/index.mdx)) |
