---
title: Устройства
description: Как отправить всё трафик одного устройства через туннель или, наоборот, полностью исключить устройство.
---

Вкладка **Устройства** — аналог маршрутизации по приложениям на телефоне, только для целых
устройств в сети.

| Режим | Что происходит |
| --- | --- |
| **Всё через туннель** | весь трафик устройства идёт через «Авто», даже в режиме «по спискам». Удобно для телевизора или приставки |
| **Ничего через туннель** | устройство полностью исключено, даже в режиме «весь трафик». Удобно для рабочего компьютера или банковских приложений |

Прямые правила работают и для устройств «всё через туннель»: например, российские сайты
останутся напрямую, если включён такой пресет.

Устройство выбирается по IP-адресу; в списке есть подсказки из таблицы DHCP. Закрепите за
устройством статический адрес (**Сеть → DHCP и DNS → Статические аренды**), иначе после
переподключения оно может получить другой адрес.
