---
title: We1ssConnect для OpenWrt
description: Клиент для роутеров на OpenWrt 24.10 и 25.12 — один туннель для всех устройств дома, с автовыбором сервера, маршрутизацией по спискам и страницами в LuCI.
---

Пакет для роутера делает то же, что приложение на телефоне, но сразу для всех устройств в
сети: телевизоров, приставок, ноутбуков, умных колонок. Ставить что-то на каждое устройство не
нужно.

## Что умеет

- **Подписки We1ssBoard и ключи**: VLESS (Reality, Vision, TLS, WebSocket, gRPC, HTTPUpgrade),
  VMess, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard, SOCKS, AnyTLS. Трафик и срок подписки
  видны на странице серверов.
- **Авто**: балансировщик выбирает сервер с наименьшей задержкой и сам переходит на другой, если
  сервер перестал отвечать. Закрепить конкретный сервер можно одним нажатием, без перезапуска
  туннеля.
- **Четыре режима, которые сочетаются**:
  - **по спискам** — через туннель идут только нужные сайты и сервисы, остальное напрямую;
  - **весь трафик** — через туннель идёт всё, кроме прямых правил;
  - **по устройствам** — отдельное устройство целиком через туннель или целиком мимо него;
  - **через интерфейсы роутера** — часть трафика через уже настроенный WireGuard, AmneziaWG,
    OpenVPN.
- **Готовые списки**: YouTube, Telegram, Discord, Meta, X, «Заблокированное в России» и другие
  списки сообщества, пресеты «Российские сайты и IP» и «Реклама и трекеры», свои домены,
  подсети и удалённые списки.
- **DNS**: DNS через HTTPS или TLS, отдельный DNS для прямых сайтов, перехват DNS устройств,
  у которых он прописан вручную.
- **Обзор в LuCI**: состояние, текущий сервер, внешний IP со страной и провайдером, трафик,
  проверка скорости, диагностика и журнал.
- **Команда `we1ssconnect`** для SSH и скриптов.

## Требования

| | |
| --- | --- |
| OpenWrt | 24.10 (пакеты `.ipk`) или 25.12 (пакеты `.apk`) |
| Память | около 25 МБ свободного места на флеше: столько занимает sing-box |
| Оперативная память | от 128 МБ, комфортно от 256 МБ |
| Процессор | любой, для которого в OpenWrt есть пакет `sing-box` |

На роутерах с флешем 16 МБ sing-box не помещается.

## Чем отличается от приложения

Роутер работает на **sing-box** из пакетов OpenWrt, а не на Xray. Отсюда два ограничения:

- ключи с транспортом **XHTTP** импортируются, но помечаются «не поддерживается» и в туннель
  не попадают;
- у автовыбора есть только режим **«по задержке»**, режима «по кругу» нет.

Остальное работает так же, как на телефоне.

## Чем отличается от podkop

Если вы пользовались [podkop](https://podkop.net), всё знакомо: секции podkop здесь называются
правилами маршрутизации, списки сообщества те же. Дополнительно есть подписки с трафиком и
сроком, автовыбор с закреплением сервера без перезапуска, режим «весь трафик», правила для
отдельных устройств, проверка скорости и внешнего IP. Одновременно с podkop пакет не ставится:
они перехватывают трафик одинаково.
