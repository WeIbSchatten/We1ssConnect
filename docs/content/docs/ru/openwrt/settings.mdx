Настройки вступают в силу после **Сохранить и применить**, туннель при этом перезапускается.

## DNS

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Протокол DNS | DNS через HTTPS | DoH, DoT или обычный UDP |
| DNS-сервер | 1.1.1.1 | резолвер для всего, что не идёт напрямую; адрес или ссылка DoH |
| DNS для прямых сайтов | 77.88.8.8 | для прямых правил, чтобы российские сайты открывались с ближайших серверов |
| Начальный DNS | 77.88.8.8 | определяет адрес DNS-сервера, если тот указан именем |
| Перехватывать свой DNS устройств | вкл. | устройствам с вручную прописанным DNS (8.8.8.8 и т. п.) тоже отвечает роутер; без этого правила «по спискам» на них не работают |
| Направить dnsmasq в туннель | вкл. | выключайте, только если настраиваете dnsmasq сами: `server=127.0.0.42` |

## Сеть

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Интерфейсы LAN | br-lan | трафик с каких интерфейсов обрабатывать; добавьте гостевую сеть, если нужно |
| IPv6 | выкл. | получать и маршрутизировать IPv6 |
| NTP напрямую | вкл. | синхронизация времени идёт мимо туннеля |
| Блокировать QUIC в туннеле | выкл. | браузеры перейдут на TCP; иногда помогает с YouTube |
| Прокси для локальной сети | выкл. | SOCKS5/HTTP-прокси на роутере (порт 2080) для приложений, которым нужен прокси |

## Подключение

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| Отпечаток Chrome для Reality | вкл. | серверы Reality на Xray 26.9.8+ отклоняют часть отпечатков |
| Фрагментация TLS | выкл. | делит TLS ClientHello, чтобы DPI не прочитал имя сервера; не для Reality и QUIC |
| Адрес проверки задержки | gstatic.com/generate_204 | по нему «Авто» измеряет серверы |
| Интервал проверки | 3 мин | как часто «Авто» перепроверяет серверы |
| Порог переключения | 50 мс | «Авто» переходит на другой сервер, только если тот быстрее на эту величину |

## Списки и подписки

| Настройка | По умолчанию |
| --- | --- |
| Обновлять списки | раз в сутки |
| Скачивать списки через туннель | выкл. |
| Обновлять подписки | каждые 12 часов |

Где лежат данные: настройки — `/etc/config/we1ssconnect`, серверы —
`/etc/we1ssconnect/servers.json`, собранная конфигурация sing-box —
`/var/run/we1ssconnect/config.json`.
