---
title: Первое подключение
description: Как добавить подписку или ключи, выбрать сервер и включить туннель на роутере.
---

## 1. Добавьте серверы

Откройте **Службы → We1ssConnect → Серверы**:

- **Добавить подписку** — вставьте ссылку на подписку из панели We1ssBoard или любую другую со
  ссылками на ключи. Роутер скачает список и будет обновлять его сам (по умолчанию каждые 12
  часов, меняется в настройках).
- **Добавить ключи** — вставьте ссылки по одной в строке. Они попадут в группу «Мои ключи».

Ключи, которые sing-box не умеет обслуживать (например, с XHTTP), появятся серыми с причиной.
Они не мешают остальным.

## 2. Выберите сервер

- **Авто** — балансировщик проверяет все серверы каждые 3 минуты и берёт самый быстрый.
- Нажмите на конкретный сервер, чтобы закрепить его. Переключение не перезапускает туннель.

**Проверить задержку** измеряет задержку до всех серверов: при включённом туннеле — запросом
через каждый сервер, при выключенном — временем соединения с ним.

## 3. Выберите, что пускать через туннель

На вкладке **Маршрутизация** уже есть выключенные правила-примеры: YouTube через туннель,
российские сайты напрямую, блокировка рекламы. Включите нужные или добавьте свои
([подробнее](./routing.mdx)).

На обзоре переключатель режима:

- **По спискам** — через туннель идут только сайты и сервисы из правил;
- **Весь трафик** — через туннель идёт всё, кроме прямых правил и исключённых устройств.

## 4. Подключитесь

На **Обзоре** нажмите **Подключить**. Через несколько секунд состояние сменится на
«Подключено», появятся текущий сервер, внешний IP с флагом страны, город и провайдер. Середина
IP скрыта, нажмите на него, чтобы показать целиком. Там же **Проверка скорости**.

Если что-то не так, откройте **Диагностику**: там видно, какая часть не работает
([решение проблем](./troubleshooting.mdx)).
