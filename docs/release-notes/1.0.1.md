## We1ssConnect 1.0.1

**Что нового**
- **Честный пинг.** Задержка по умолчанию меряется до самого сервера (TCP-соединение, ICMP для Hysteria2), а не полным запросом через сервер в интернет. Цифры теперь показывают именно ваш путь до сервера. Прежний способ можно включить: Настройки → Проверка задержки → «Через сервер».
- **Пинг при включённом VPN.** Кнопка «Проверить задержку» работает без отключения, а список обновляется сам раз в 30 секунд.
- **Свои окна.** Подтверждения, ошибки и меню нарисованы в стиле приложения, а не системными окнами Android.
- **Дизайн как в панели.** Значок W в заголовке, карточки с рамкой и мягкой тенью, полоса со скоростью и трафиком за сеанс.

**What's new**
- **Honest ping.** Delay is measured to the server itself by default (TCP connect, ICMP for Hysteria2) instead of a full request through it. The old test is in Settings → Delay test → "Through the server".
- **Ping while connected.** "Test delay" works without disconnecting, and the list refreshes itself every 30 seconds.
- **Own dialogs.** Confirmations, errors and menus match the app instead of Android's system dialogs.
- **Panel-like design.** The W mark in the header, bordered cards with a soft shadow, a strip with speed and session traffic.
