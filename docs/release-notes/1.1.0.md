## We1ssConnect 1.1.0

**Что нового**
- **Windows и Linux.** We1ssConnect теперь есть на компьютере: те же экраны, что на телефоне, — серверы, подписки, автовыбор, маршрутизация, пинг до сервера, темы. При подключении включается системный прокси; программы, которые его не видят, можно направить на SOCKS5 `127.0.0.1:10808` или HTTP `127.0.0.1:10809`.
- **Обновление на компьютере** тоже из приложения: Windows запускает новый установщик, Linux заменяет файл и перезапускается.

**What's new**
- **Windows and Linux.** We1ssConnect now runs on computers with the same screens as the phone: servers, subscriptions, auto select, routing, ping to the server, themes. Connecting turns on the system proxy; programs that ignore it can use SOCKS5 `127.0.0.1:10808` or HTTP `127.0.0.1:10809`.
- **Desktop updates** come from the app too: Windows starts the new installer, Linux replaces its file and restarts.

**Файлы · Files**
- `we1ssconnect-android-1.1.0-arm64-v8a.apk`, `…-armeabi-v7a.apk`: Android
- `we1ssconnect-desktop-1.1.0-windows-amd64-setup.exe`: Windows 10/11
- `we1ssconnect-desktop-1.1.0-linux-amd64`: Linux (`chmod +x`, нужен / needs WebKitGTK 4.1)
