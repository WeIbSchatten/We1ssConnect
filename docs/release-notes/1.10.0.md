## We1ssConnect 1.10.0

Новый экран подключения, работа в фоне и исправления роутера · A new connect screen, background mode and router fixes

**Что нового**
- **Кнопка подключения показывает состояние движением:** спокойные кольца, пока VPN выключен, бегущая дуга во время подключения, а после — мягкое свечение и точки на орбите, которые бегут быстрее при большом трафике. Заголовки и цифры набраны шрифтом Onest, переключатели плавно двигают выделение. Если в системе включено уменьшение анимации, движение отключается.
- **Работа в фоне.** Android: если система выгрузила приложение, VPN поднимается снова сам, в том числе как «Постоянная VPN»; в настройках появился пункт «Работа в фоне», который снимает ограничения экономии батареи. Компьютер: закрытие окна больше не отключает VPN — приложение уходит в трей (Открыть, Подключить / отключить, Выход).

**Что исправлено**
- **Блокировка рекламы и «русские сайты напрямую».** Файлы правил скачивались только из релизов GitHub, которые сейчас отвечают ошибкой 504 или заблокированы; без них подключение не поднималось вовсе. Теперь они скачиваются с raw.githubusercontent.com, а если не удалось — VPN подключается без этих правил и предупреждает. Реклама дополнительно блокируется на уровне DNS.
- **QR-код:** камера показывала картинку, но не распознавала код в релизной сборке.
- **Роутер:** sing-box падал при запуске, потому что сам скачивал списки с GitHub. Теперь списки скачивает клиент и хранит на флеше; недостающие докачиваются через туннель, а при сбое GitHub берутся текстовые версии с raw.githubusercontent.com. Запуск больше не ждёт сети.
- **Роутер:** ссылка на подписку, вставленная в поле ключей, добавляется как подписка; после установки сразу включено правило «Заблокированное в России + YouTube».
- **Роутер:** если на флеше нет места для Xray (нужно 33 МБ), клиент сразу об этом пишет и не скачивает архив каждый час; временные файлы (~45 МБ в памяти) удаляются.

**What's new**
- **The connect button shows its state in motion:** still rings while the VPN is off, a sweeping arc while connecting, then a soft glow with satellites that orbit faster under heavy traffic. Headings and figures use Onest, toggles slide their highlight. Motion stops when the system asks for reduced motion.
- **Background mode.** Android: when the system kills the app the VPN comes back by itself, also as Always-on VPN; Settings has a "Run in the background" item that lifts battery restrictions. Desktop: closing the window no longer disconnects — the app goes to the tray (Open, Connect / disconnect, Quit).

**What's fixed**
- **Ad blocking and "Russian sites directly".** The rule files came only from GitHub release downloads, which now answer 504 or are blocked; without them the connection did not come up at all. They now come from raw.githubusercontent.com, and if that fails the VPN connects without those rules and says so. Ads are also blocked in DNS.
- **QR codes:** the camera showed a picture but read no code in release builds.
- **Router:** sing-box died at start because it downloaded the lists from GitHub itself. The client now downloads them and keeps them on flash; missing ones come through the tunnel, falling back to the text lists on raw.githubusercontent.com when GitHub fails. Starting no longer waits on the network.
- **Router:** a subscription URL pasted among keys becomes a subscription; the "Blocked in Russia + YouTube" rule is on after install.
- **Router:** when Xray does not fit on the flash (it needs 33 MB) the client says so at once instead of downloading the archive every hour, and its ~45 MB of temporary files in RAM are removed.
