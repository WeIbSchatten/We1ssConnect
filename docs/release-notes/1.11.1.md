## We1ssConnect 1.11.1

Обновление на роутере с занятой флешкой · Router updates on a fuller flash

**Что исправлено**
- **Роутер не обновлялся** с ошибкой «Not enough flash: sing-box needs about 25 MB free»: установщик требовал места под sing-box даже тогда, когда он уже установлен. Теперь для обновления хватает 2 МБ, 25 МБ нужны только при первой установке.
- **Неудачное обновление было не видно:** LuCI писал «обновление идёт в фоне» и снова предлагал ту же версию. Теперь обзор показывает, почему последнее обновление не удалось.
- **Обновление молча обрывалось при скачивании:** встроенный wget (uclient-fetch) сдавался на первом адресе github.com, который не ответил. Теперь пакеты скачиваются через curl с повторами, а если скачать всё же не вышло, установщик пишет, какой файл не загрузился.

**What's fixed**
- **The router did not update** ("Not enough flash: sing-box needs about 25 MB free"): the installer asked for room for sing-box even when it was already installed. An update now needs 2 MB; 25 MB is only needed for the first install.
- **A failed update was invisible:** LuCI said "updating in the background" and offered the same version again. The overview now says why the last update failed.
- **An update stopped silently while downloading:** the built-in wget (uclient-fetch) gave up on the first github.com address that did not answer. Packages now download through curl with retries, and if a download still fails the installer names the file.
