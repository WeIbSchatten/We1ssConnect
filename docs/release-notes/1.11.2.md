## We1ssConnect 1.11.2

Маршрутизация на роутере текстом · Router routing rules as text

**Что нового**
- **Правила маршрутизации текстом.** На странице «Маршрутизация» кнопка «Текстом» показывает все правила одним списком, по правилу на строку: `domain(geosite:ru-blocked)->proxy`, `geoip(telegram)->proxy`, `domain(geosite:category-ads-all)->block`. Список можно править, вставить из заметок или перенести на другой роутер. Кнопка «Формой» возвращает обычный вид. Ошибки видны по строкам ещё до сохранения.
- **Правила по протоколу:** `protocol(bittorrent)->direct` отправляет торренты напрямую, когда остальной трафик идёт через туннель.

**What's new**
- **Routing rules as text.** The "As text" button on the Routing page shows all rules as one list, one rule per line: `domain(geosite:ru-blocked)->proxy`, `geoip(telegram)->proxy`, `domain(geosite:category-ads-all)->block`. Edit it, paste it from your notes or copy it to another router; "As a form" brings the usual view back. Errors show by line before you save.
- **Rules by protocol:** `protocol(bittorrent)->direct` sends torrents direct while the rest goes through the tunnel.

Приложения для Android, Windows и Linux не менялись: в релизе их файлы 1.11.1. · The Android, Windows and Linux apps are unchanged; this release carries their 1.11.1 files.
