## We1ssConnect 1.9.0

**Что нового**
- **We1ssConnect для роутеров OpenWrt 24.10 и 25.12.** Один туннель сразу для всех устройств дома: подписки We1ssBoard и ключи, «Авто» по задержке с закреплением сервера без перезапуска, маршрутизация по спискам (YouTube, Telegram, Discord, «Заблокированное в России» и другие), режим «весь трафик», правила для отдельных устройств и для VPN-интерфейсов роутера, DNS через HTTPS. Управление на страницах LuCI и командой `we1ssconnect`.
- **Новый сайт документации** с поиском, на русском и английском, со ссылками на документацию панели We1ssBoard.
- **Версии клиентов идут вслед за панелью:** 1.9.x у клиентов соответствует 1.9.x у We1ssBoard.

Установка на роутер, по SSH:

```sh
wget -qO- https://raw.githubusercontent.com/WeIbSchatten/We1ssConnect/main/openwrt/install.sh | sh
```

На роутере используется sing-box из пакетов OpenWrt, поэтому ключи с XHTTP там не поддерживаются, а у «Авто» нет режима «по кругу».

**What's new**
- **We1ssConnect for OpenWrt 24.10 and 25.12 routers.** One tunnel for every device at home: We1ssBoard subscriptions and keys, the lowest-delay Auto with pinning without a restart, routing by lists (YouTube, Telegram, Discord, "Blocked in Russia" and more), an all-traffic mode, rules for single devices and for the router's VPN interfaces, DNS over HTTPS. Managed from LuCI pages and the `we1ssconnect` command.
- **A new documentation site** with search, in Russian and English, linked with the We1ssBoard panel docs.
- **Client versions follow the panel:** clients 1.9.x go with We1ssBoard 1.9.x.

The router uses sing-box from the OpenWrt packages, so XHTTP keys are not supported there and Auto has no round-robin mode.
