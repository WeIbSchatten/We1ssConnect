## We1ssConnect 1.9.3

Исправления клиента для роутера OpenWrt · Fixes for the OpenWrt router client

**Что исправлено**
- **REALITY с новыми панелями.** Xray начиная с 26.9.8 (We1ssBoard ставит 26.10.21) не пускает клиентов REALITY без постквантового ключа X25519MLKEM768, а sing-box его не отправляет. Теперь роутер ведёт серверы REALITY через Xray: при первом подключении он сам скачивается с GitHub (около 30 МБ на флеше), проверяется контрольная сумма, и Xray запускается рядом с sing-box. Если установлен `xray-core` 26.3.27 или новее из пакетов, используется он. Остальные серверы идут через sing-box, как раньше.
- **Hysteria2 и TUIC** не подключались: sing-box не принимает отпечаток браузера поверх QUIC, а ссылки панели его содержат. Отпечаток для них больше не передаётся.
- **WebSocket и HTTPUpgrade поверх TLS** не подключались к Xray: клиент предлагал HTTP/2, и сервер обрывал соединение. Для этих транспортов теперь только HTTP/1.1.
- **Проверка задержки** всегда показывала −1, теперь каждый сервер проверяется отдельно.
- **«Маршрутизация не работает»:** если в выборочном режиме ни одно правило не ведёт в туннель, обзор об этом предупреждает. Предупреждения в LuCI переведены на русский.
- **Диагностика** больше не ругается на маршрутизацию, если podkop переименовал таблицу 105; добавлена проверка Xray.
- Сохранённые серверы и подписки исправляются сами, импортировать их заново не нужно.

**What's fixed**
- **REALITY with new panels.** Xray 26.9.8 and later (We1ssBoard ships 26.10.21) turn away REALITY clients without the post-quantum X25519MLKEM768 key share, and sing-box sends none. The router now carries REALITY servers through Xray: on the first connect it downloads itself from GitHub (about 30 MB of flash), its checksum is verified and it runs next to sing-box. A packaged `xray-core` 26.3.27 or later is used instead when installed. Every other server stays in sing-box.
- **Hysteria2 and TUIC** did not connect: sing-box refuses a browser fingerprint over QUIC, and panel links carry one. It is no longer passed for them.
- **WebSocket and HTTPUpgrade over TLS** did not connect to Xray: the client offered HTTP/2 and the server dropped the connection. These transports now use HTTP/1.1 only.
- **The delay test** always showed −1; each server is now tested on its own.
- **"Routing does not work":** when no rule in selective mode leads into the tunnel, the overview says so. LuCI warnings are translated.
- **Diagnostics** no longer flag routing when podkop renamed table 105, and check Xray.
- Stored servers and subscriptions are fixed by themselves, no re-import needed.
