# Установка и обновление

## Какой файл скачать

На [странице последнего релиза](https://github.com/WeIbSchatten/We1ssConnect/releases/latest)
лежат два APK:

| Файл | Для чего |
| --- | --- |
| `we1ssconnect-android-<версия>-arm64-v8a.apk` | почти все телефоны последних лет |
| `we1ssconnect-android-<версия>-armeabi-v7a.apk` | старые и бюджетные 32-битные телефоны |
| `SHA256SUMS` | контрольные суммы, чтобы проверить файл |

Если не знаете, какой нужен, берите `arm64-v8a`. Если телефон скажет, что приложение
несовместимо, поставьте `armeabi-v7a`.

## Установка

1. Скачайте APK на телефон.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или
   файлового менеджера): разрешите.
3. При первом подключении приложение попросит разрешение на VPN. Нажмите «ОК»: без него Android
   не даст создать туннель.
4. На Android 13+ разрешите уведомления. По ним видно, что VPN работает, и из них можно
   отключиться.

## Обновление

Приложение проверяет новые версии само, не чаще раза в шесть часов. Когда выходит новая,
на главном экране и в **Настройки → Обновления** появляется карточка «Доступна версия…».

1. Нажмите **Скачать и установить**. Приложение скачает APK именно для вашего процессора.
2. Откроется системный установщик. Если Android попросит, разрешите We1ssConnect устанавливать
   приложения: это нужно один раз.
3. Подтвердите обновление. Серверы, подписки и настройки сохранятся.

Проверить вручную можно кнопкой **Проверить обновления** в настройках.

> Все версии подписаны одним ключом, поэтому новая ставится поверх старой. Если вы ставили
> тестовую сборку из CI с другим ключом, её нужно удалить перед установкой релиза.

## Удаление

Удалите приложение как обычно. Вместе с ним удаляются серверы, подписки и скачанные правила.
