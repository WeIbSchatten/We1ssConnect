# Первое подключение

## 1. Добавьте серверы

Откройте вкладку **Серверы** и нажмите **+**. Подойдёт любой из вариантов:

- **Ссылка на подписку** из панели We1ssBoard или другой панели: `https://…`. Приложение
  скачает список серверов и будет обновлять его.
- **Ссылки на ключи**: `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, по одной
  на строку. Они сохранятся отдельной группой; ей можно дать имя.
- **QR-код**: кнопка **Сканировать QR-код** откроет камеру.
- **Буфер обмена**: кнопка **Вставить из буфера**.

Из панели We1ssBoard можно открыть приложение сразу с подпиской по ссылке
`we1ssconnect://add?url=<ссылка на подписку>`.

## 2. Выберите сервер

После добавления приложение само проверит задержку до всех серверов. Можно:

- оставить **Авто**, и балансировщик сам будет выбирать сервер ([подробнее](/ru/balancer.md));
- выбрать конкретный сервер в списке.

Цифра справа — задержка: зелёная до 300 мс, жёлтая выше, красная «нет ответа».

## 3. Подключитесь

На **Главной** нажмите большую кнопку. Через пару секунд она станет зелёной, и появятся:

- **Ваш IP**: адрес, через который вас видят сайты. Середина скрыта, нажмите на адрес, чтобы
  показать его целиком;
- флаг и название **страны**, город и провайдер;
- **скорость** загрузки и отдачи, трафик и время сеанса;
- для подписок — сколько трафика израсходовано и до какой даты она действует.

Выбор другого сервера во время подключения применяется сразу, без переподключения.
