# Все настройки

Настройки, отмеченные «⟳», меняют конфигурацию ядра: если VPN включён, приложение
переподключится само.

## Маршрутизация

| Настройка | По умолчанию | |
| --- | --- | --- |
| Маршрутизация по приложениям | все приложения | [подробнее](/ru/routing.md#по-приложениям) |
| Локальная сеть напрямую ⟳ | вкл. | домашние устройства без VPN |
| Российские сайты напрямую ⟳ | выкл. | [пресеты](/ru/routing.md#пресеты) |
| Блокировать рекламу ⟳ | выкл. | [пресеты](/ru/routing.md#пресеты) |
| Обновить правила маршрутизации | — | скачивает `geoip.dat` и `geosite.dat` заново |

## Подключение

| Настройка | По умолчанию | |
| --- | --- | --- |
| Отпечаток Chrome для Reality ⟳ | вкл. | см. ниже |
| Фрагментация TLS ⟳ | выкл. | см. ниже |
| Мультиплексирование (mux) ⟳ | выкл. | см. ниже |
| Проверять задержку при запуске | вкл. | замер всех серверов при открытии приложения, когда VPN выключен |
| Обновлять подписки при запуске | вкл. | подписки старше 12 часов обновляются при открытии |

**Отпечаток Chrome для Reality.** Начиная с Xray 26.9.8 сервер Reality молча отклоняет
клиентов, которые не отправляют X25519MLKEM768 в ClientHello. Так ведут себя отпечатки
`ios`, `edge`, `android` и `random`. Настройка заменяет отпечаток на `chrome`, который нужное
отправляет. Оставьте её включённой, если не знаете, зачем выключать.

**Фрагментация TLS.** Первое сообщение TLS (в нём видно имя сервера) режется на мелкие куски с
паузами, и DPI не может прочитать его целиком. Помогает, когда блокируют TLS-серверы по имени.
Применяется к серверам на TLS и Reality поверх TCP, на Hysteria2 не влияет.

**Мультиплексирование.** Много соединений идут внутри одного соединения с сервером, что
ускоряет открытие сайтов на медленных каналах. Не применяется к XTLS Vision, XHTTP и Hysteria2:
они с mux не работают или в нём не нуждаются.

## Оформление

| Настройка | Варианты |
| --- | --- |
| Тема | Система, Светлая, Тёмная, AMOLED (чистый чёрный фон, экономит заряд на OLED-экранах) |
| Цвета | Океан, Изумруд, Пастель, Моно — те же пресеты, что в панели We1ssBoard |
| Язык | Русский или English; приложение перезапустится |
